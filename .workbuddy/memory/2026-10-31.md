# 2026-10-31

## oracle2excel 项目初版交付

- 需求: 从上游 Oracle 11g 导出数据到 Excel，Python + oracle_conn.json 配置，Docker Compose 部署，镜像打包 TGZ。
- 关键技术决策: python-oracledb Thin 模式只支持 DB 12.1+，**11g 必须用 Thick 模式 + Instant Client 19**（已查官方文档确认）。镜像打包 IC 19.25 Basic + libaio1，设置 ORACLE_HOME/LD_LIBRARY_PATH/TNS_ADMIN/NLS_LANG，DSN 用 makedsn service_name。
- 交付物: app/{config,db,exporter,logger,main}.py、config/oracle_conn.json、Dockerfile、docker-compose.yml、build.sh（build+save 成 dist/*.tar.gz）、tests/test_export.py（mock oracledb 端到端 39 项断言全过）、README.md。
- 深度检查修复的 bug: ①LOB output_type_handler 定义了但没注册到连接；②分 Sheet 切换时表头未复用；③build.sh 的 docker run 缺 -i 导致 stdin 验证脚本静默空跑；④文件名清洗被绕过；⑤ENV 中 \$LD_LIBRARY_PATH 不会运行时展开。
- 环境限制: 沙箱无 Docker 且无 root，镜像构建/打包需用户在有 Docker 的机器上跑 `./build.sh`。发现用户本机 ORACLE_HOME 指向 ~/.local/lib/oracle/instantclient_19_29（本机装有 IC 19.29）。
- 运行模式: once（跑完退出）/ loop（周期导出），退出码 0/2/3/4。
- 追加 run.sh: 一次性 docker run --rm 运行（挂载 config:ro + output，透传退出码，NETWORK=host 可选，镜像不存在时提示先 build/load）。
- 追加 install_docker.sh: Ubuntu 安装 Docker Engine + Compose（默认阿里云源，OFFICIAL=1 切官方，代号不在镜像源时自动回退）。沙箱无 root 无法代跑，需用户 sudo 执行后再 ./build.sh 导出 dist/。
